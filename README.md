# Touchless-Hand-Gesture-Whiteboard
An interactive, touchless whiteboard controlled entirely by hand gestures — no mouse, no keyboard, just gestures and creativity!

**Overview**
This project takes hand gesture recognition to the next level by enabling users to draw, change colors, clear the canvas, and save their artwork using only predefined hand gestures. Built for real-time use with smooth interactions and a simple UI.

**Gesture Controls**
👍 Like – Start drawing
✊ Fist – Switch drawing color
🤘 Rock – Clear the canvas
👎 Dislike – Save your artwork
✋ Open Palm – Pause drawing

**How It Works**
	•	SVM Classifier trained on custom hand gesture data
	•	Real-time hand tracking using MediaPipe
	•	Custom canvas manager handles drawing logic, color switching, and gesture interpretation

**Technologies Used**
	•	Python
	•	OpenCV
	•	MediaPipe
	•	Scikit-learn
	•	NumPy
